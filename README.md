# Focus App

Windows 桌面專注工具，提供番茄鐘、倒數計時器、碼表和 YouTube 背景音樂。

介面使用隨 App 附帶的 Noto Sans TC 字型，主時鐘保留原本的 Courier New，計時數字採用等寬數字排列。Noto Sans TC 依 `fonts/OFL.txt` 授權，離線時也能正常顯示；背景影片仍需要網路。

## 使用方式

啟動後可從左上角工具列開啟番茄鐘、倒數計時器、碼表或設定。在「現在專注於」輸入事項，再開始番茄鐘；該次工作階段會綁定開始時輸入的事項。完成工作階段後，「今日完成」會加一，事項的次數與分鐘數也會更新，並可展開「查看專注紀錄」查看最近 10 次完成紀錄。暫停、重設及休息結束都不計入。工具也可透過桌面空白處的右鍵選單開啟。

App 內的「❔ 說明」和桌面右鍵選單的「使用說明」提供完整操作指引，按右上角 ✕、Esc 或點說明視窗外側可關閉。

「設定」可選擇番茄鐘、碼表、倒數計時器、時鐘數字、左上角工具列、底部播放器、音樂選曲面板、設定面板、使用說明及右鍵選單，分別調整顏色和背景不透明度（0–100%）。「還原此元件」只重設目前選取的元件，「還原全部外觀」重設所有元件的顏色與透明度，不會清除專注紀錄或背景檔案。設定視窗可拖曳標題列移動，位置會記住。舊版已儲存的三種計時工具顏色與共同透明度會自動沿用。

番茄鐘預設工作 25 分鐘、休息 5 分鐘，會自動切換並播放提示音；工作與休息時長可分別設定為 1–180 分鐘和 1–60 分鐘。倒數計時器可設定時、分、秒。鈴聲響起時，背景影片音量暫時降至原本的 20%，結束後恢復。兩種鈴聲都可以各自關閉。

在音樂面板按「管理曲目」，貼上 YouTube 影片網址即可新增音樂，也可填入自訂曲目名稱；預設加入「自訂」，按「指定分類」並填入名稱可加入現有分類或建立新分類。管理模式中可刪除曲目，分類內沒有曲目時會自動消失。新增與刪除會保存在本機，重新開啟 App 後仍會保留。內建「輝夜姬」分類有五首曲目。

播放器偵測到直播時，時長會顯示「🔴 直播」並停用進度拖曳；一般影片仍顯示播放時間與總長度。

在「設定」的背景區，可選原本影片、單張照片、照片輪播或本機影片。照片可一次選取多張，輪播間隔為 3–30 秒；本機影片會靜音循環播放。選用自訂背景後，原本的 YouTube 影片預設出現在右上角；直接拖曳影片可移動，拖曳右下角可調整大小，位置與尺寸都會記住。按 ✕ 隱藏後可從設定重新打開；隱藏只影響畫面，音樂繼續播放。新選取的照片與影片會複製到 Electron 使用者資料目錄的 `background-assets` 資料夾，選擇清單儲存在同目錄的 `background-media.json`；重開 App 後仍能使用，原始檔移動也不影響。舊版已選但尚未複製的背景，重新選取一次即可匯入。

目前事項、最近 200 次完成紀錄、番茄鐘時長、提示音開關、介面顏色、視窗位置和背景模式儲存在 Electron 使用者資料目錄的 `preferences.json`。今日完成次數在新的一天重新計算。YouTube 影片需要網路連線，並受影片可用性影響；計時器、本機鈴聲與已選取的本機背景不依賴網路。

啟動時先顯示操作介面，再開始載入 YouTube 播放器。儲存的設定只在啟動時讀取；選取背景檔案時才會複製照片或影片。

## 開發與啟動

需要 Node.js 與 npm。於專案目錄執行：

```powershell
npm ci
npm start
```

Windows 也可在安裝依賴後雙擊 `start.bat`。執行 `npm test` 可檢查計時和鈴聲邏輯。

## 客戶交付

在 Windows 上安裝依賴並通過測試後執行：

```powershell
.\build-portable.ps1
```

指令會在 `release` 產生帶時間戳記的 Windows 便攜版 ZIP。解壓縮後執行 `FocusApp.exe`，客戶不需要安裝 Node.js。首次使用背景影片時需要網路。
